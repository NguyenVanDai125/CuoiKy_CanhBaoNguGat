# Hệ thống Giám sát và Phát hiện Cảnh báo Ngủ gật

Dự án phát triển hệ thống giám sát thời gian thực nhằm phát hiện trạng thái buồn ngủ và đưa ra cảnh báo kịp thời qua webcam.

## Công nghệ sử dụng
- Python 3.11+
- MediaPipe, OpenCV, PyAutoGUI, Numpy
- Quản lý môi trường bằng `uv`
